Volcano Hybrid

Personal Bluetooth control for your Storz & Bickel Volcano Hybrid. Built for Bluefy on iPhone (or Chrome / Edge on desktop and Android).

Web Bluetooth isn’t available in this browser This page can’t reach the Volcano from here. On iPhone, open this same page in the Bluefy — Web BLE Browser app. On desktop or Android, use Chrome or Edge. Safari and Firefox don’t support Web Bluetooth. Your saved workflows below still work — only the live connection needs a Bluetooth-capable browser.
One connection at a time The Volcano accepts a single Bluetooth connection. While this app is connected, the official S&B app is locked out — and if the official app is connected, this one can’t connect. Disconnect here when you’re done.
Auto-off always runs The moment the heater or the pump starts, the device’s auto-off countdown starts too. When it hits zero, both switch off. Watch the countdown below and set your auto-off time in Settings.

Workflows — your sequences, your rules

A workflow is a sequence of steps. Each step sets a target temperature, waits until the device itself confirms it reached that temperature, holds, then runs the pump. Steps never advance on a timer alone — no confirmation, no advance. Workflows live only on this phone (saved in this browser) and are fully editable — unlike the official web app’s fixed presets.

Activity & safety log

Every command is recorded here before it is sent. If the connection drops, anything still pending is discarded — it is never replayed when you reconnect, and a queued “on” command is never replayed under any circumstances.
